## 0.1.0

- Initial release.
- Text field with the whole API of `TextField` and Codecs. Its decoration is merged with the Validation Message, never replaced.
- Checkbox, switch, radio group (with an option that stands for null), slider, dropdown, date picker, time picker and segmented control.
- Every widget is a `FormidableFieldWidget`, so each takes `messages`, `errorDisplay` and `focusNode`.
- Validation Messages shown through the Material decoration, with the error display policy of the Form.
