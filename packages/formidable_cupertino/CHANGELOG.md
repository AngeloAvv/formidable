## 0.1.0

- Initial release.
- Text field with the whole API of `CupertinoTextField` and Codecs, switch, checkbox, segmented control, sliding segmented control, radio group, slider, date picker and timer picker.
- Every widget is a `FormidableFieldWidget`, so each takes `messages`, `errorDisplay` and `focusNode`.
- Validation Messages shown under each widget, with the error display policy of the Form.
