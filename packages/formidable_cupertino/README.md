# formidable_cupertino

Cupertino widgets for Formidable, built on cupertino_ui and the headless Binding. A text field (with Codecs), switch, checkbox, segmented and sliding segmented controls, radio group, slider, and date and timer pickers.

This package is part of [Formidable](https://github.com/AngeloAvv/formidable). See the [documentation](https://docs.page/AngeloAvv/formidable) to get started.
