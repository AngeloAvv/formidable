# formidable_flutter example

`formidable_flutter` is the widget-agnostic layer of Formidable: the Form Scope, the reactive Builders, Listeners and Selectors, and the Field Widget base class. It is built only on the widgets library, so it has no app of its own. Pair it with a widget package and run that example instead:

- [Material example](https://github.com/AngeloAvv/formidable/tree/main/packages/formidable_material/example): a sign-up page with the Material Field Widgets.
- [Cupertino example](https://github.com/AngeloAvv/formidable/tree/main/packages/formidable_cupertino/example): the same page with the Cupertino Field Widgets.
- [Example app](https://github.com/AngeloAvv/formidable/tree/main/example): every feature as a runnable app, each guide shown in Material and in Cupertino side by side.

See the [documentation](https://docs.page/AngeloAvv/formidable) for the rest.
