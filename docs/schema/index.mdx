# Declaring a Schema

A Schema is a plain Dart class marked with `@Formidable()`. Each final field becomes a Field, and the Schema constructor is used to build the output of a valid Form.

See [Getting Started](/getting-started) for a complete example.

This section grows with the library. See [Required and optional Fields](/schema/presence) for Unset versus null, defaults, `@Required()` and Passthrough Fields. Later pages cover inheritance, positional constructors and the diagnostics the generator reports for a Schema that cannot become a Form.
