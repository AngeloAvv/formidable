# Network Validators

These Validators judge a `String` Field. Each has a typed error and a message in English, Italian, Spanish, French and German.

```dart
@Formidable()
class Server {
  const Server({required this.address, required this.subnet, required this.host});

  @Ip(IpVersion.v4)
  final String address;

  @Cidr()
  final String subnet;

  @Fqdn()
  final String host;
}
```

| Annotation | Passes when | Error |
|---|---|---|
| `Ip([version])` | The value is an IPv4 address (no leading zeros, octets up to 255) or an IPv6 address. `IpVersion.v4`, `IpVersion.v6` or `IpVersion.any` (the default) pick the family. | `FormidableIpError(version)` |
| `Cidr([version])` | The value is an address of the family, a slash and a prefix: up to 32 for IPv4 and 128 for IPv6, with no leading zeros. | `FormidableCidrError(version)` |
| `MacAddress()` | Six bytes in hexadecimal, with colons (`00:1A:2B:3C:4D:5E`), hyphens (`00-1A-...`) or dots in groups of four (`001A.2B3C.4D5E`). The separator cannot be mixed. | `FormidableMacAddressError` |
| `Hostname()` | One or more dot separated labels of letters, digits and hyphens, each up to 63 characters and not starting or ending with a hyphen, at most 253 characters in all. `localhost` is valid. | `FormidableHostnameError` |
| `Fqdn()` | A host name of at least two labels whose last label is not all digits. A single trailing dot is allowed. | `FormidableFqdnError` |
| `Domain()` | At least two valid labels, no trailing dot, and a top level domain of two or more letters (or an `xn--` one). | `FormidableDomainError` |
| `Latitude()` | A decimal number from -90 to 90. | `FormidableLatitudeError` |
| `Longitude()` | A decimal number from -180 to 180. | `FormidableLongitudeError` |
| `LatLng()` | A latitude and a longitude separated by a comma, such as `45.4642, 9.19`. | `FormidableLatLngError` |

Domain names are checked by shape. Formidable does not know the list of existing top level domains, and it does not look names up: to check that a domain exists, write an Async Validator.

Coordinates are decimal numbers written as text, so use these Validators on `String` Fields. For `double` Fields use the number Validators.
