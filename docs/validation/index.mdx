# Validators

A Validator is a synchronous rule declared as an annotation on a Field. It returns zero or more typed Validation Errors and runs only while the Field has a value.

`@MinLength` is used in [Getting Started](/getting-started). The built-in catalog has one reference page per category, listed below.

Write your own rules in [Custom Validators](/validation/custom).

How an error turns into the text the user reads, in five languages, is covered in [Messages and localization](/validation/messages).
