# Validators

A Validator is a synchronous rule declared as an annotation on a Field. It returns zero or more typed Validation Errors and runs only while the Field has a value.

Today the library ships `@MinLength`, used in [Getting Started](/getting-started). The built-in catalog and cross-field rules arrive in later releases, with one reference page per category.

Write your own rules in [Custom Validators](/validation/custom).

How an error turns into the text the user reads, in five languages, is covered in [Messages and localization](/validation/messages).

## Built-in catalog

- [Number Validators](/validation/numbers)
- [Date Validators](/validation/dates)
- [Choice and equality Validators](/validation/choices)

Rules that call a service run through [Asynchronous validation](/validation/async).
