# Binding Fields to widgets

Two layers connect a Field to a widget:

- **The headless Binding** (`FormidableBinding`, created by `FormidableBindingBuilder`) keeps the value, the focus and the errors of one Field in sync with one widget. It draws nothing, so it works with any widget, including third-party ones. It owns its focus node and text controller unless you pass your own, and it never disposes the ones you pass.
- **Convenience widgets** for Material (`formidable_material`) and Cupertino (`formidable_cupertino`) are thin layers over the Binding.

Available today: `FormidableTextField` for Material. Build any other widget from `FormidableBindingBuilder`:

```dart
FormidableBindingBuilder<String>(
  field: form.username,
  formatText: (value) => value,
  parseText: (text) => text.isEmpty ? null : text,
  builder: (context, binding) => TextField(
    controller: binding.textController,
    focusNode: binding.focusNode,
    onChanged: binding.onTextChanged,
    decoration: InputDecoration(errorText: binding.errorText),
  ),
)
```

`binding.errorText` is null until the Field is touched. A Field becomes touched when a focusable widget loses focus. Call `binding.onTouched()` for a widget that cannot take focus.
